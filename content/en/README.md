# Unibook Documentation

Unibook supports spot and perpetual trading, vaults, and integration through the v1 API.

## Traders

Start with [Getting started](guides/getting-started.md), then read about [Trading and orders](guides/trading.md), [Margin and funding](guides/margin-and-funding.md), [Vaults](guides/vaults.md), and [Deposits and withdrawals](guides/deposits-and-withdrawals.md).

## Developers

Begin with the [Quickstart](developers/quickstart.md), then read [Signing and authorization](developers/authentication.md), [REST conventions](developers/rest-api.md), [WebSocket](developers/websocket.md), and [Errors and recovery](developers/errors-and-recovery.md). The [API Reference](api/README.md) groups public v1 endpoints by function.

API and business behavior may change between versions. Networks, assets, markets, and parameters depend on your environment. These guides do not assume a public API hostname.
