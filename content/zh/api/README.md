# API 参考

本参考使用同一份公开 v1 OpenAPI 规格。API 字段与协议保持英文；中文指南解释接入流程。

价格、数量和金额的缩放、签名以及回执处理请先阅读开发者指南。账户数据频道不代表保密访问。

交互请求需要实际交易网关地址；本规格的相对服务器地址不能用于 GitBook 域名。签名写请求需要先在客户端生成签名。
