# DEXOS 文档

DEXOS 支持现货和永续交易，并提供金库及 v1 API 接入能力。

## 交易用户

从[开始使用](guides/getting-started.md)了解账户和交易流程，继续阅读[下单与成交](guides/trading.md)、[保证金与资金费](guides/margin-and-funding.md)、[金库](guides/vaults.md)及[入金与提款](guides/deposits-and-withdrawals.md)。

## 开发者

从[快速接入](developers/quickstart.md)开始，阅读[签名与授权](developers/authentication.md)、[REST 使用约定](developers/rest-api.md)、[WebSocket](developers/websocket.md)及[错误与恢复](developers/errors-and-recovery.md)。[API 参考](api/README.md)按业务分类列出公开 v1 接口。

接口和业务行为会随版本更新；实际支持的网络、资产、市场和参数以所用环境为准。本文不预设公开 API 域名。
