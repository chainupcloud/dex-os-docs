# 开始使用

Unibook 支持永续合约与现货交易。两种交易共用账户，但资产用途不同：现货是全额买卖，永续合约需要保证金，并可能产生资金费和清算。

## 第一笔交易

1. 确认当前站点的网络、支持资产及市场。测试网资产与真实资产不同，不要跨网络转账。
2. 连接你控制的钱包，确认操作的账户。主账户、子账户和金库账户的余额与风险不能混为一谈。
3. 按[入金与提款](deposits-and-withdrawals.md)核对网络、代币合约及收款地址，先用小额验证到账。
4. 阅读市场的价格步长、数量步长、手续费和交易状态；永续交易还要核对保证金、杠杆与资金费。
5. 设置价格、数量和订单有效方式，核对钱包签名的操作后提交。
6. 查看订单状态、成交记录及账户余额。提交成功不等于全部成交。

## 账户与授权

同一钱包可以拥有多个账户。子账户用于分别管理资金和仓位；同一账户内的永续仓位通常共享保证金。转到另一个账户不会自动转移原账户的订单或仓位。

API 钱包是主钱包授权的交易密钥，可执行授权范围内的交易操作，不能提款或转账。授权有自己的有效期；不用时应撤销。不要把主钱包私钥或 API 钱包私钥交给他人。
